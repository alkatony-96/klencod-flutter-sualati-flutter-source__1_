# سؤالاتي

تطبيق Flutter عربي (Dart) لإنشاء الاختبارات وإدارة الأسئلة وحفظها وطباعتها. الواجهة كاملة باللغة العربية وبتخطيط من اليمين إلى اليسار.

## ما الذي يقدمه؟

- إنشاء اختبارات مع اسم المادة والصف والمدة والتعليمات.
- كتابة أسئلة اختيار من متعدد، وصح/خطأ، وإجابة تحريرية، وأكمل الفراغ.
- تحديد الدرجة لكل سؤال والإجابة الصحيحة، مع حساب مجموع الدرجات تلقائيًا.
- تعديل الاختبارات والأسئلة أو حذفها.
- حفظ مكتبة الاختبارات محليًا على الجهاز.
- إنشاء ملف PDF عربي بخط Noto Naskh Arabic مضمّن، ثم مشاركته/حفظه من قائمة المشاركة أو إرساله إلى الطابعة.
- إرفاق نموذج إجابة اختياري في ملف PDF.

## إنشاء مشروع Android وiOS كامل

يحتاج البناء إلى تثبيت Flutter وDart على جهازك. لأن Flutter SDK غير متوفر في بيئة إعداد هذه الملفات، أُرفق سكربت ينشئ ملفات المنصات الأصلية ثم ينسخ التطبيق إليها.

```bash
chmod +x bootstrap.sh
./bootstrap.sh /المسار/الذي/تريده/sualati-app
cd /المسار/الذي/تريده/sualati-app
flutter run
```

يمكن أيضًا ترك المسار فارغًا لإنشاء المشروع بجانب مجلد المصدر باسم `sualati-app`:

```bash
./bootstrap.sh
```

لتجربة التطبيق على Android، وصّل هاتفًا مع تفعيل USB debugging أو شغّل محاكيًا. لنسخة iOS يلزم Xcode على macOS. بعد تجهيز المشروع يمكن فتح مجلد Android في Android Studio أو بناء APK باستخدام `flutter build apk`.

## ملاحظات

- الاختبارات محفوظة داخل التطبيق على الجهاز، ولا تُرفع إلى خدمة سحابية.
- تصدير PDF والطباعة يعتمدان على إضافتي Flutter `printing` و`pdf`.
- صيغة البيانات محلية وبسيطة، لذا أزل التطبيق قد يمسح بياناته بحسب إعدادات الجهاز؛ احتفظ بملفات PDF المهمة خارج التطبيق.
